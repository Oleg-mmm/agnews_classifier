# my_learn_nlp

Учебный проект по NLP: классификация коротких текстов на PyTorch
через усреднённые эмбеддинги (bag of embeddings).

## Что делает

- Токенизация текста (`.lower().split()`)
- Словарь `Vocab` с `<pad>` и `<unk>`
- Датасет `TextClsDataset` с паддингом и маской
- Модель `BagOfEmbedding`: `Embedding` → маскированное усреднение → `Linear`
- Обучение на маленьком демонстрационном наборе (8 фраз, 2 класса): "животные" (0) vs "погода" (1)
- Инференс через `predict()`
